# QazPhysics — адаптивті физика курсы

Оқушыларға арналған геймификацияланған адаптивті физика онлайн-курсы.

## Мүмкіндіктер

- 45 деңгейлік тапсырма және адаптивті квиз
- XP, прогресс және Physics Quest ойыны
- Виртуалды тәжірибелер
- Қателерді қайталау режимі
- Сертификат
- Қазақша және орысша интерфейс
- Ақ және қара режим
- Телефонға бейімделген дизайн

## Іске қосу

Жоба таза HTML, CSS және JavaScript арқылы жасалған. `index.html` файлын браузерде ашыңыз немесе VS Code-та Live Server арқылы іске қосыңыз.

## GitHub Pages

1. Осы папкадағы барлық файлды GitHub репозиторийіне жүктеңіз.
2. GitHub-та **Settings → Pages** бөліміне өтіңіз.
3. **Deploy from a branch**, `main` және `/ (root)` таңдаңыз.
4. Сақтағаннан кейін сайт GitHub Pages сілтемесінде ашылады.
